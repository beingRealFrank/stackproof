Guard hook

Blocks force-push, --no-verify, rm -rf on root or home, curl | sh, git reset --hard origin/..., database wipes, production targets and unscoped dependency updates, and edits to generated or third-party files. Turn it off for one session with STACKPROOF_GUARD=off claude.

Verification

Verified on lobsters@28bc8d6: 6/6 cases, suite 0.92 vs 0.78 without the kit. Fixture: https://github.com/lobsters/lobsters. Evaluated 2026-11-15.

Install

unzip stackproof-rails-<version>.zip -d ~/stackproof
claude plugin marketplace add ~/stackproof/stackproof-rails
claude plugin install rails-kit@stackproof-rails

Then in your project: /rails-kit:init. Price: $29 one-time.
