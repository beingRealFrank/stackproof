Guard hook

Blocks force-push, --no-verify, rm -rf on root or home, curl | sh, git reset --hard origin/..., database wipes, production targets and unscoped dependency updates, and edits to generated or third-party files. Turn it off for one session with STACKPROOF_GUARD=off claude.

Verification

Verified on localgov_directories@af3551c: 5/6 cases, suite 0.86 vs 0.65 without the kit. Fixture: https://github.com/localgovdrupal/localgov_directories. Evaluated 2026-11-13.

Install

unzip stackproof-drupal11-<version>.zip -d ~/stackproof
claude plugin marketplace add ~/stackproof/stackproof-drupal11
claude plugin install drupal11-kit@stackproof-drupal11

Then in your project: /drupal11-kit:init. Price: $29 one-time.
