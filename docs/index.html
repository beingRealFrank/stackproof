How we verify

Each kit is run against a pinned commit of a real public repository. The same prompts run with and without the kit, and the results are graded by file checks and a judge model. The scores are on each kit's page.

FAQ

What's in a kit?

Six skills (including init, which writes your CLAUDE.md), three subagents, a guard hook that blocks destructive commands and edits to generated or third-party files, a format hook that runs your project's own formatter, and a help command.

How are kits verified?

Each kit is tested with Claude Code's plugin eval runner against a pinned commit of a real open-source project, with and without the kit. The results are on the kit's page.

What about privacy?

The kits make no network calls and collect nothing. The hooks run locally and only read the command or file path Claude is about to use.

Are updates free?

Updates are free. Download the newest zip from the customer portal linked in your Polar receipt email and unzip it over the old folder.

What is the license?

Solo: one developer, any number of projects. Team: up to 10 developers at one company. Don't redistribute the files.

Refunds?

If a kit doesn't work for your project, email within 14 days of purchase for a full refund.
